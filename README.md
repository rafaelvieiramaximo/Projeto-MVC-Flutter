# Flutter App - Projeto MVC Five Screens

Aplicativo Flutter simples com navegação entre telas, estilização personalizada e uso de fontes externas.

## ✨ Funcionalidades

- Navegação entre múltiplas páginas
- Estilização com tema personalizado
- Botões arredondados e sombreados
- Uso de cores customizadas em hexadecimal
- Fontes externas integradas (`Quicksand` e `Fredoka`)
- Layout responsivo com espaçamentos organizados por tela

## 🛠 Tecnologias

- [Flutter](https://flutter.dev/) 3.7.2
- Dart
- Fontes externas (`Google Fonts`)
- Gerenciamento de pacotes via `pubspec.yaml`

## 📱 Telas

O app possui múltiplas telas com personagens como Bart, Meme Girl, Pelé e Smurf. Cada tela contém:
- Texto com estilo customizado
- Botões estilizados com cores específicas
- Navegação entre páginas


## 🔤 Fontes Usadas

- [Fredoka](https://fonts.google.com/specimen/Fredoka)
- [Quicksand](https://fonts.google.com/specimen/Quicksand)

As fontes estão localizadas na pasta:
```
assets/fonts/
```
